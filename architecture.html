Each block is a stage in Nostromo's dispatch engine. The planned loop runs once per hour; the real-time loop runs every minute and can override the plan within safe limits.

Hourly · day-ahead

① The planned loop

Cooling & power forecasts, the site's physical limits and the meter cap (+ buffer) feed the Composer, which builds an hourly discharge plan — a target for what the meter should read each hour. Pre-PCT translates that into service rules (water-side stability, charge/discharge windows, durations); PCT Calculation turns the rules into concrete numbers and writes the Power Control Table.

forecast in→ Composer→ rules→ hourly table
Minutely · live

② The real-time loop

The IRM (Nostromo's own meter at the main-meter point) and chiller kW stream in every minute. Real-time Adjustments compares the live meter to the planned target plus a buffer and decides to discharge more/less, charge, or stop charging. Post-PCT writes the corrected rows and HCS executes the current row on the plant immediately.

live metervs target→ adjust→ execute now

What keeps the real-time loop safe

  • Meter vs target + buffer. The core trigger — act only once the live meter drifts past the planned target by more than the deadband.
  • SOC pacing. Meter discharge against remaining stored cooling vs remaining peak hours so the store never runs dry before the peak ends.
  • Supply-temp guard. The 60°F supply to the data center is a hard constraint — temperature always wins over a kW target.
  • Hysteresis. A deadband on charge↔discharge so the system never oscillates minute-to-minute.
