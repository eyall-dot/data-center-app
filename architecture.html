Each block is a stage in Nostromo's dispatch engine. The planned loop runs once per hour; the real-time loop runs every minute and can override the plan within safe limits.

Hourly · day-ahead

① The planned loop

Weather and power forecasts, site physical limits and the meter cap feed the Composer, which builds an hourly discharge plan — a kW target for each hour of the day. That plan flows down to the real-time layer as its baseline.

forecast in→ Composer→ hourly plan
Minutely · live

② The real-time loop

Every minute, the IRM meter and live chiller draw stream in. Real-time Adjustments compares the live picture to the planned target: an IT load uptick triggers more discharge; a gap below the cap can start or ramp a charge cycle; if charging risks pushing the meter to the cap, a stop signal goes out immediately. The result is a mode trigger sent straight to HCS, which acts on the Nostromo IceBrick without delay.

live meter→ compare→ mode trigger→ HCS

What keeps the real-time loop safe

  • Live meter vs planned target. Act when the meter drifts past the planned discharge target by more than the deadband.
  • IT load uptick detection. Rising IT power triggers an increase in discharge to keep the meter below cap.
  • Charge-gap opportunism. Gap between current consumption and meter limit triggers initiation or ramping of a charge cycle.
  • Hard cap guard. If charging risks bringing the meter to within the safety buffer of the cap, stop charging immediately.
